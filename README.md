# 天才交易员 · 宏观交易教学模拟器

一个**单文件、纯前端、无后端**的宏观经济与交易机制教学演示：用宏观基本面、利率贴现、预期差、多空博弈驱动四个板块与个股的价格，你在有限回合里判断方向与仓位、择机平仓，最后结算评级。

> ## ⚠️ 免责声明（请务必先读）
>
> 本项目是**编程与宏观经济教学演示工具**，不是交易软件，也不是投顾产品。
>
> - 页面内所有行情、K 线、宏观数据、利率、新闻与事件，**均由浏览器端程序随机生成**，与真实市场、真实机构、真实标的无关；程序**不接入任何行情源、交易接口或资金账户**，**不涉及任何资金**。
> - 界面中出现的**全部公司名称与证券代码都是虚构示例**（如「星珩科技」「锐垣科技」、代码 `S8101` / `EF101`），**不对应任何真实上市公司、证券或机构**；其中的业绩、立案、退市等情节同样为虚构，不代表对任何真实主体的评价。如有雷同，纯属巧合。
> - 本项目**不构成任何投资建议**，不承诺任何收益，请勿把模拟结果用于现实投资决策。
> - 模拟盘**不含融资与杠杆功能**：做多只用现金，做空为无保证金的反向下注，不会欠钱、不会爆仓。现实中的融资融券有维持担保比例、强平线与利息，规则与此完全不同，**切勿照此操作**。
> - 存档仅保存在用户浏览器本地（`localStorage`），不上传任何服务器；清除缓存、无痕模式或更换设备会丢失对局。

## 一、怎么跑起来

没有构建步骤、没有依赖、没有后端，整个程序就在 `index.html` 一个文件里。

```text
方式 1：双击 index.html，用浏览器打开（推荐 Chrome / Edge）
方式 2：拖进任意静态托管 —— GitHub Pages / Gitee Pages / 免费静态主机 / 自己的 Nginx
```

### 部署到 GitHub Pages

1. 新建 Public 仓库，把本目录下所有文件（`index.html`、`README.md`、`LICENSE`、`.nojekyll`、`备份/`）上传到仓库根目录；
2. 仓库 `Settings → Pages`，Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存；
3. 等 1–2 分钟，访问：

```text
https://<你的用户名>.github.io/<仓库名>/
```

> `.nojekyll` 用于让 Pages 关闭 Jekyll 处理、原样发布文件，别删。

## 二、玩法概览

| 要素 | 说明 |
| --- | --- |
| 起始资金 | 10,000（虚拟数字） |
| 目标笔数 | 默认 20 笔，对局设置里可改，也可选「无限制」一直交易 |
| 标的 | 科技 / 消费 / 金融 / 能源 四个板块，每板块 5 只普通股 + 1 只风险警示股（ST），共 24 只个股；另有 4 只板块指数 ETF 与 1 只债券 ETF |
| 债券 | 走反向逻辑：利率上、债价跌，是最直接的对冲工具 |
| 交易动作 | 做多、做空、平仓，以及加仓 / 减仓一半 / 全部平仓 |
| 仓位比例 | 轻 10% / 半 30% / 重 50%，吸底交易条与挂单浮层**共享同一状态**，随手可换 |
| 挂单 | 限价挂单，到价以挂单价成交；挂单不占资金，成交时才扣款；可直接点 K 线图上某个价位自动填价 |
| 节奏 | 每日拍数 5 / 10 / 20 / 30；暂停、1× / 2× / 4× 调速 |
| 开局预演 | 先自动跑 40 / 80 / 120 个交易日的历史行情，跑完才解锁交易 |
| 存档 | 每 5 拍自动存档，刷新不丢；可清档重开 |
| 导出 | 分享战绩、导出 CSV 对局日志 |

**图表可切换**：分时（逐拍曲线）/ 日 K / 周 K / 月 K；叠加指标各自独立开关——估值中枢、MA5、MA20、布林带、成交量、资金流、成本线。

## 三、市场模型（改参数前先看这段）

价格不是随机游走，而是几股力量叠加：

```text
个股价格 = 板块收益 × β + 公司 α（自身景气周期 + 长期趋势）
         + 估值回归（向 fairValue 动态中枢收敛）± 事件冲击 ± 噪声
板块价格 = 宏观因子（增长 / 流动性 / 财政 / 情绪）× 利率贴现 × 板块 β
债券价格 = 100 −（长端利率 − 2.5%）× 10
```

- **宏观**：双频正弦（长波 + 短波）叠加一条 `regime` 随机游走，避免周期机械重复；流动性有惯性地靠拢目标值。
- **板块**：每个板块有独立的景气相位、周期与趋势游走、波动聚集，四个板块不再同涨同跌。
- **回归锚**：`fairValue(sec)` 随宏观与个股盈利中枢动态变化，不是固定基准价。
- **噪声与连涨连跌**：噪声按日 K 尺度标定；连续同向行情会被自我约束打压，避免一拍到底、单边失控。

可调参数集中在文件顶部的 `CONFIG`：

```js
startBalance, totalTrades, tickMs, volatility, bondVol, fee,
maxPoints, chartRange, maxBars, newsMax, eventChance, corpEventChance
```

## 四、功能模块

### 4.1 ST 风险警示股

每个板块有一只基本面已经坏掉的 ST 股：盈利中枢只有正常公司六成左右，“股价便宜”往往是价值陷阱（合理估值本身就低）。

- **涨跌幅限制 ±5%**（普通股 ±10%），消息对价格影响更强、盘口更薄，容易涨停封板与连续跌停；
- **专属资讯池**：年报亏损、审计意见、债务违约、监管立案、保壳重组、摘帽预期；
- **财报季状态机**（每 240 拍结算一次）：
  - 普通股长期亏损 → 戴帽 `ST`；
  - 风险累积到 82 → 升级 `*ST`（退市风险警示）；
  - 盈利中枢回到 0.90 以上、风险降到 30 以下 → **摘帽**，涨跌幅放开到 ±10%，估值向新中枢收敛；
- 界面用橙色 `ST / *ST` 徽章标记，详情页给出「退市风险 N/100」。

### 4.2 退市开关（默认关闭）

对局设置里的「允许退市（真实规则）」，**默认关闭，即教学版不退市**。

- **关闭时**：ST 最坏只到 `*ST` 与一条终止上市风险提示，股票永远可交易，持仓不会被强平；
- **开启时**：`*ST` 风险打满 → 进入**退市整理期**（10 个交易日，涨跌幅放宽到 ±10%，盘口极薄、持续抛压）→ 期满**摘牌**：持仓按最后价格清算入账，标的灰化、停止交易，再下单会被拦截；
- 摘牌后价格、估值线、K 线全部冻结，不再随行情变动。

### 4.3 大手模式（政策工具箱，默认关闭）

「对局设置」里打开大手模式后，出现政策工具箱；**关闭时这套设置整体隐藏且完全不参与定价**。

- 可调：财政支出强度、税率、支出倾斜方向（基建 / 民生 / 产业补贴）、政策利率方向、流动性投放；
- **六套快捷模板**：稳增长 / 减税惠民 / 产业扶持 / 降温紧缩 / 滞胀应对 / 危机救援；
- **供给冲击**：能源涨价 / 技术断供 / 解除管制，属外生事件，按下即生效、线性衰减，同一时间只保留一种；
- **政策时滞**：先经历内部时滞（约一个交易日拍板落地），再经历外部时滞（约三个交易日逐步见效），有传导进度条；力度过猛会推高通胀与赤字、累积债务率，反过来抬利率、压估值。

### 4.4 资讯与传闻真伪

- **资讯密度三档**：精简 / 标准 / 详细，只控制推送节奏，不改变事件对价格的作用；政策、黑天鹅与证实/辟谣在精简档也会即时出现；
- **传闻**：标明来源与可信度，过几拍才揭晓「证实 / 辟谣」——迟到的真相决定谁被套；
- **强提醒**：跌停 / 涨停封板、戴帽、升级 `*ST`、摘帽、进入整理期、摘牌清算等价格突变，顶部弹一条强提醒，写清「发生了什么、为什么、后果是什么」；涨跌停提醒只对当前在看与持仓中的标的弹出，避免刷屏。

### 4.5 资金流向

叠加指标行的「资金流」开关（默认关闭）。主力净流入强度跟随价格方向、消息冲击与多空力量，带惯性并向 0 回归，**只表征资金行为，不反过来参与定价**。

- 图表底部画零轴双向柱：红柱向上为净流入，绿柱向下为净流出；
- 成交量与资金流同开时，底部区上下分两条，互不重叠；
- 报价行显示主力净流入占成交的比例。

> 教学提示：资金流会被大单对倒、诱多诱空制造假象，需结合估值、传闻真伪与消息面一起判断，不能单凭红柱多就追。

## 五、代码结构导览

单文件，全部逻辑在 `index.html` 内，顺序为：`<style>` → DOM 骨架 → `<script>`。

**状态**

```js
state = {cash, sectors, idx, current, lastOf, macro, rates, expect, pos, ratio:0.3,
         trades, streak, best, finished, timer, paused, speed, activeEvents,
         newsFeed, chartRange, log, tickNo, preSim, preDaysTarget, orders, rumors,
         depth, policy}
state.ui = {rounds, showPower, newsDensity, allowDelist, fair, ma, band, vol, flow,
            cost, barsPerDay:10, period:'day', preDays:40, eventLevel:2}
```

**关键函数**

| 函数 | 职责 |
| --- | --- |
| `marketStep()` | 纯推进一拍市场（不改 UI，预演与实盘复用） |
| `tick()` | 一拍 = `marketStep()` + 挂单撮合 + 定期存档 + `render()` |
| `nextStockPrice()` | 个股定价：板块 β + 公司 α + 估值回归 + 事件 + 噪声 |
| `fairValue()` | 动态估值中枢；摘牌后返回冻结快照 |
| `stStatusStep()` | ST 财报季结算：戴帽 / 升级 / 摘帽 |
| `delistSec()` | 摘牌清算：持仓按最后价入账，标的停止交易 |
| `openPos / addPos / reducePos / closeSec / closeAll` | 开仓与平仓（含做空） |
| `placeOrder / cancelOrder / checkOrders / executeOrder` | 限价挂单全流程 |
| `drawChart / drawTickChart / buildView` | 日 / 周 / 月聚合与绘制、分时绘制 |
| `pushNews / resolveRumors` | 资讯推送（受密度预算约束）与传闻揭晓 |
| `applyPreset / applyShock` | 政策模板与供给冲击 |
| `render / renderDock / renderOrders / renderPos` | 各区域刷新 |
| `saveGame / loadGame / reset` | `localStorage` 存档（key：`tt_save_v8`） |

**响应式断点**（CSS 内有注释）：单栏 < 480px；双栏 480–1179px；三栏 ≥ 1180px；超宽 ≥ 1600px。

## 六、已知坑（都是踩过的）

- `file://` 下 `navigator.clipboard` 可能不可用，代码里已有 `execCommand` 兜底；
- 浏览器对同名本地文件缓存顽固：版本号写进文件名，顶栏有 `vN · 视口 xxpx · 单栏/双栏` 徽章，白屏时先看徽章判断是不是旧文件；
- 无头浏览器最小窗口约 496px，更窄的截图是裁切假象，不是布局坏了；
- K 线图设价依赖 `state.chartMap`（每次绘制记录绘图区上下边界），改绘图区尺寸时记得同步更新；
- 移动端资讯列表用原生滚动 + `overscroll-behavior:contain`，不要再给 `body` 加 `overflow:hidden`，否则整页会冻死；
- 老存档里的公司名 / 代码会在 `loadGame` 时按当前定义自动纠正，不需要清档。
